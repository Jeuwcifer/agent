# ui-analyzer

## Description
Analyzes screenshots of web application UIs to improve accessibility and user-friendliness. Triggers when the user attaches an image and says "Review this UI", "analyze this UI", "critique this design", "improve this layout", or "review this interface".

## Instructions
1. **Analyze:** Review the provided UI screenshot focusing strictly on accessibility (e.g., WCAG guidelines, color contrast, readability) and user-friendliness (UX heuristics, tap targets, cognitive load).
2. **Critique:** Identify specific usability bottlenecks, poor contrast, missing affordances, or accessibility violations.
3. **Suggest:** Provide concrete, actionable recommendations to resolve the identified issues.
4. **Format:** Output findings exclusively as a concise bulleted list.
